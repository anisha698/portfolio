An interactive snowglobe that responds to your phone

A SwiftUI experiment where snow particles react to real-world motion using the iPhone's gyroscope, shake the phone and it feels like actually playing with a snowglobe.

TypeSelf-initiated · prototype
RoleConcept · UI · Prototype
Year2026
ToolsFigma · SwiftUI · Xcode · Cursor
01 / 02

From sketch to working app

I designed the layout in Figma and then vibe-coded the build in SwiftUI / Xcode with help from Cursor, starting as a complete beginner in SwiftUI. The core challenge was hooking the iPhone's gyroscope into a particle system so the snow drifted, settled, and scattered with real physical-feeling motion.

Building it taught me how much more there is to development beyond designing screens, motion tuning, performance, and a long tail of tiny edge cases that you only discover once you ship something to a real device. It pushed me to keep experimenting with bridging visual and interaction design with real, working apps.
